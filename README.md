# 당근 PC 가성비 분석기

내부 테스트용 로컬 대시보드입니다. `조회하기`를 누르면 로컬 Vite 서버가 지정된 당근 검색 조건의 결과를 요청하고 브라우저에서 분석합니다. 계정이나 외부 저장 서버는 없습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열고 **조회하기**를 누르면 해운대구·수영구의 판매중·10만~30만 원·PC 조건 매물을 통합 분석합니다. 여러 동네에 함께 노출된 매물은 자동으로 중복 제거하며, 별도 확장 프로그램 설치는 필요하지 않습니다.

## 검증

```bash
npm test
npm run build
```

당근 화면 구조가 바뀌어 자동 추출이 되지 않는 경우, 대시보드의 수동 입력란에 `제목 | 가격` 형식으로 등록하고 사양을 보정할 수 있습니다.
